Wind River Cloud Platform

Wind River Cloud Platform(WRCP)은 starlingx를 기반으로 Wind River가 상용화·검증·지원하는 분산 사설 클라우드 인프라 제품이다. Kubernetes를 기반으로 KubeVirt와 선택형 Wind River OpenStack을 통해 VM·컨테이너 워크로드를 지원하며, 작은 엣지 노드에서 중앙 데이터센터까지 lifecycle, fault, security와 성능 관리를 통합하는 데 초점을 둔다. StarlingX FAQ도 WRCP가 StarlingX 기반 상용 배포판임을 명시한다. 원문 원문

KubeVirt와 OpenStack의 두 경로

  • KubeVirt: 동일 Kubernetes 클러스터에서 VM과 컨테이너를 관리한다. 제품 설명은 KubeVirt system application에 CDI와 virtctl이 포함된다고 명시한다.
  • Wind River OpenStack: 컨테이너화된 OpenStack 제어 서비스를 Kubernetes 위에 배포하여 OpenStack API 및 전통적 VM 인프라를 제공한다.

따라서 “WRCP가 KubeVirt 플랫폼이다”라고만 설명하면 불완전하다. WRCP는 기반 인프라·분산 수명주기 플랫폼이고, KubeVirt와 OpenStack은 요구에 따라 선택하는 VM 실행·관리 계층이다. 원문

제품화된 운영 계층

  • 호스트 하드웨어·OS·플랫폼 서비스의 Day 0~2 수명주기와 fault recovery
  • 중앙에서 subcloud를 관리하는 분산 클라우드 및 zero-touch provisioning
  • rolling/in-place upgrade, inventory와 구성 관리
  • Wind River Conductor를 통한 배포·오케스트레이션
  • Wind River Analytics를 통한 플랫폼 및 OpenStack/KubeVirt Pod 관찰성
  • Ceph/Rook 기반 분산 스토리지와 외부 FC/iSCSI/NFS 연동
  • SR-IOV, DPDK, CPU Manager, Topology Manager, hugepage 등 저지연·고성능 기능

이 항목 중 최대 노드 수, 다운타임, 성능 수치 등은 공급업체가 제시한 제품 주장이다. 도입 시 해당 릴리스, 하드웨어 BOM, 참조 아키텍처와 고객 인수시험으로 검증해야 한다. 원문 원문

StarlingX와의 차이

구분StarlingXWind River Cloud Platform
성격커뮤니티 오픈소스 통합 프로젝트StarlingX 기반 상용 제품·지원 배포판
운영 책임사용자가 통합·검증·지원 체계를 설계공급업체의 테스트, hardening, lifecycle 및 지원 제공
부가 제품공개 프로젝트 기능 중심Conductor, Analytics, Wind River OpenStack 등 제품군 결합
적합 조직자체 플랫폼 엔지니어링 역량이 강한 조직SLA·상용 지원·인증된 lifecycle이 필요한 통신/산업/엔터프라이즈

강점

  • 통신·산업·미션 크리티컬 분산 엣지의 작은 footprint와 저지연 요구
  • KubeVirt와 OpenStack을 모두 제공해 VM 현대화 속도를 선택할 수 있음
  • 하드웨어부터 subcloud fleet까지 통합 lifecycle 및 fault management
  • 상용 지원과 사전 통합을 통해 검증 부담을 줄이는 방향

제약과 검증 항목

  • 라이선스·구독, 하드웨어 인증, 전문 운영도구 의존성을 TCO와 exit plan에 반영한다.
  • KubeVirt와 OpenStack 중 어느 VM 경로가 표준인지 워크로드군별로 결정해 운영 이중화를 방지한다.
  • 공급업체 성능·가용성 주장을 실제 사이트 규모, 네트워크 단절, 업그레이드와 장애 주입 시험으로 검증한다.
  • upstream StarlingX/KubeVirt와 제품 릴리스의 버전 지연 및 기능 차이를 확인한다.
  • openshift-virtualization과 비교할 때 앱 개발 플랫폼이 아니라 분산 인프라·엣지 lifecycle이 핵심 가치임을 구분한다.

전체 선택 분석은 kubevirt-platform-comparison을 참고한다.
